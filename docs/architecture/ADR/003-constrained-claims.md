# ADR-003 — Evidence-first ответ через проверенные claims

Status: proposed. Date: 2026-10-09. Approval: пользователь G0.

Context: схема C проверяет документы/ссылки после LLM. Реальный URL не гарантирует поддержку сказанного, а независимая LLM-проверка также может ошибаться и увеличивает расход.

Decision: Comparison Engine создаёт facts/calculation/comparison claims с operands/evidence; LLM выдаёт только разрешённый порядок и template codes. Backend рендерит цифры/даты/условия/ссылки. Для поиска текста — точная цитата и backend metadata. Неподтверждённый свободный текст не публикуется. Нет отдельного judge-agent.

Alternatives: свободный ответ + URL whitelist недостаточен; второй LLM judge дорог и не даёт строгого доказательства; чисто шаблонный бот допустим как fallback. Выбран ограниченный LLM для intent/структуры и детерминированные содержательные утверждения.

Consequences: менее свободный стиль, но можно проверять каждое существенное утверждение; число внешних calls ограничено. Произвольные вопросы могут требовать уточнения или давать цитаты вместо красивого пересказа. Это принципиальное продуктовое ограничение следует согласовать, не скрывать.

Affected: AI-001/002/003, LLM-001/002/003, UI-003, DOMAIN_CONTRACTS, EVALUATION_PLAN. Tests: подменённое число, настоящее URL без поддержки, неизвестный claim, injection, provider timeout. Migration: новые response schema versions; старые answers immutable, не переписывать renderer задним числом.
