## Алгоритм и подзадачи

1. **JOB-001.01** — enqueue_due транзакционно фиксирует slot и next_check_at.
2. **JOB-001.02** — Claim SKIP LOCKED, commit до сети, heartbeat30s/lease180s.
3. **JOB-001.03** — Выполнить dispatch по type и проверять fencing token при каждом commit результата.
4. **JOB-001.04** — Retry 3 attempts с backoff/jitter; expired lease requeue; deterministic failure blocked до изменения входа.

## Обработка ошибок и границы

Два scheduler/worker не выполняют одну публикацию; старый worker после lease expiry не пишет; process crash оставляет recoverable job.

Ошибки фиксировать кодом и request/job ID без secrets/полного текста чата. Не скрывать неготовую внешнюю зависимость за успешной заглушкой. Изменения должны оставлять прежние доказательства доступными.

## Тесты и фикстуры

Два DB connections claim race; frozen clock expiry; kill worker; Retry-After cap; duplicate enqueue; no sleeping transaction.

Unit проверки детерминированы; SQL integration использует PostgreSQL, а не SQLite. Network/provider tests offline с Fake, live probes только по source policy. Для bug fix добавить regression по поведению. Зафиксировать fixture hashes и фактические команды в отчёте.
