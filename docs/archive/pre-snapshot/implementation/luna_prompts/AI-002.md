## Ограничения

Сохраняй immutable originals и evidence; Decimal без float; unknown≠0; current≠latest fetched; private history owner-only. LLM не считает тарифы и не генерирует URLs/pages/dates. Provider не выбран, Fake используется до отдельного решения. Не добавляй vector DB, Kafka, Kubernetes, agent framework. Нельзя обходить защиту банков или отправлять сообщения/email. При изменении центрального контракта подготовь ADR и укажи affected tasks.

## Реализация

Контракт: Explain JSON ordered_claim_ids/template_by_claim; AnswerEnvelope и citations backend-owned.

1. **AI-002.01** — Создать registry templates для facts/comparison/limitations и typed parameters.
2. **AI-002.02** — Проверить все claim IDs, operands, allowed templates, evidence page/quote/applicability.
3. **AI-002.03** — Собрать text/table/links из backend data; LLM выбирает допустимый порядок.
4. **AI-002.04** — На invalid output вернуть deterministic table+limitations без второго judge call.

Ошибки и границы: Existing URL без supporting claim не проходит; unknown claim/свободная цифра/выдуманная дата →reject.
