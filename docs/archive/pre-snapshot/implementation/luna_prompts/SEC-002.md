## Реализация

Контракт: Threat matrix SECURITY и typed tool/claim boundaries.

1. **SEC-002.01** — Создать malicious HTML/PDF/footnote fixtures и fake DNS/redirect transport.
2. **SEC-002.02** — Проверить actual peer IP policy, IPv6/local/private/metadata, dangerous subresources.
3. **SEC-002.03** — Проверить source instructions не меняют tools/output и не exfiltrate.
4. **SEC-002.04** — Проверить XSS escaped snippets, unsafe links, parser memory/time quotas и safe fallback.

Ошибки и границы: Нельзя выдавать clean bill только по system prompt; sandbox escape/SSRF/invented claim release blocker.
