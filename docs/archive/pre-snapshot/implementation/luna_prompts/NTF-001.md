## Реализация

Контракт: Subscription filters bank/metric, notifications own-only, channel=in_app.

1. **NTF-001.01** — Создать owned CRUD subscriptions с canonical filter hash.
2. **NTF-001.02** — Outbox worker выбирает committed events, применяет filters и inserts on conflict do nothing.
3. **NTF-001.03** — Read/unread notifications, cursor stable, baseline suppressed.
4. **NTF-001.04** — Retry failed delivery с leases и metrics; не отправлять email/SMS.

Ошибки и границы: Crash after insert before ack не создаёт дубль; disabled subscription не получает новые события; чужой notification404.
