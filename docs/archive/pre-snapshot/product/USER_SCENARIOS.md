# Сценарии и состояния интерфейса

| ID | Действие | Ожидаемое поведение |
|---|---|---|
| U01 | «Чем Сбер выгоднее Альфа-Банка?» | Сравнить одинаковые критерии/контекст; показать преимущества любой стороны, unknown отдельно; не придумывать общий winner |
| U02 | «А теперь сравни его с ВТБ» | focus_bank остаётся Сбер, comparator=ВТБ; новые факты извлекаются заново |
| U03 | «Комиссии за последний месяц» | Уточнить: текущие комиссии или изменения; для «изменения за 30 дней» фильтр detected_at с явным интервалом |
| U04 | Нажать источник в таблице | Полный архивный PDF именно использованной редакции; page fragment если известен; ссылка официального сайта отдельно |
| U05 | Источник банка 3 дня недоступен | Last-known данные помечены stale, дата проверки видима, winner не заявляется без ограничения |
| U06 | У банка «условия индивидуальны» | Показать текст и источник, стоимость «по договору», comparison insufficient |
| U07 | Аналитик видит противоречие | Оригинал, кандидаты, сноски, даты; approve/reject/needs_changes с причиной; audit и optimistic lock |
| U08 | Два клика «Отправить»/reconnect | Один question run, восстановление polling, нет повторного списания budget |
| U09 | LLM timeout | Сохранить проверенную таблицу и шаблонный вывод; не терять вопрос; явное сообщение о fallback |
| U10 | Удаление истории | Чат исчезает, context и queued jobs отменены; старый run не возвращает данные |
| U11 | Подписка на банк | Уведомление только подтверждённого события; raw HTML redesign не создаёт тарифную тревогу |
| U12 | Номер страницы неизвестен | Открывается полный документ без выдуманного page label |

## Разделы

Dashboard: покрытие банков и критериев, last checked/parse, pending review count для analyst, recent confirmed changes. Не ставить «0 ₽» в неполученной ячейке.

AI Assistant: список сообщений, вопрос, scenario chips (регион/дата/банки), status queued/running, AnswerEnvelope с ограничениями и источниками. Tables остаются читабельными при 4 банках, горизонтальная прокрутка на узком экране. Отмена ожидания не обещает отмену уже отправленного provider запроса, но повтор не создаёт новый.

Bank Comparison: фильтры, сценарий, единицы/плательщик/условия рядом со значением, comparison date и freshness. Доступен без LLM.

Changes Feed: occurred/detected/effective даты различаются; announced/activated/correction помечены. Documents: фильтры банк/тип/версия, full original и section/page. Chat History: только собственные чаты, удалить с предупреждением об удалении, восстановить context выбора. Settings: subscriptions и retention/preferences. Admin/Analyst: source health, job logs без secrets, users/invites; отдельная review queue с evidence.

Общие состояния: skeleton только до data response; пусто ≠ ошибка; 401 → login, 403 → доступ ограничен, 409 → обновить версию без потери ввода, 429 → retry countdown, offline → сохранить локально только неотправленный текст текущего экрана (без долговременного browser storage по умолчанию), 503 → retry. Focus/keyboard labels, semantic tables и контраст проверяются UI tests.
