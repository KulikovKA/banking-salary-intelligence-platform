Причина уровня reasoning: Исполнитель Astra по исходному распределению ролей; Luna не проводит собственный независимый аудит.

Делай checkpoint после каждого внутреннего этапа, не останавливая разрешённую работу на ненужное повторное подтверждение.

Это независимая проверка, назначенная Astra; Luna может подготовить имеющиеся отчёты, но не подменяет независимый аудит.
