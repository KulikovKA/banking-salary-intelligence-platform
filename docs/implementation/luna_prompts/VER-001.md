## Реализация

Контракт: VersionDecision{raw_changed,canonical_changed,reprocess_required,reason}; DATA_FLOW.

1. **VER-001.01** — Создавать source_version только для новых bytes, сохранять fetch observations при равенстве.
2. **VER-001.02** — Считать canonical hash только после полного parse с config version.
3. **VER-001.03** — При новой parser/config выполнять reprocess даже unchanged raw.
4. **VER-001.04** — Отделить document identity mapping от latest URL, сохранять старые extraction IDs.

Ошибки и границы: Новый PDF по старому URL сохраняется; одинаковые bytes по другому URL сохраняют provenance; failed parse не обновляет last_successful_parse.

## Тестирование

Same bytes, metadata-only changed PDF, changed fee, parser upgrade, source URL relocation, reprocess retry.

Проверь реальные результаты, зафиксируй команды и versions/fixtures; не выдавай непроведённую проверку за pass. Live API без согласованного provider/policy не вызывай.
