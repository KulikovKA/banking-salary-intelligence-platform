## Реализация

Контракт: POST questions202 / GET answer-runs, idempotency key, AnswerEnvelope.

1. **AI-003.01** — В одной транзакции создать user message/run/job, same-key replay возвращает run.
2. **AI-003.02** — Снять REPEATABLE READ facts/evidence/corpus revision и закрыть transaction до LLM.
3. **AI-003.03** — Выполнить safe intent→tools→comparison→renderer через gateway.
4. **AI-003.04** — Транзакционно сохранить assistant/context если session active и expected version совпадает; bounded queue/backpressure.

Ошибки и границы: Worker retry не дублирует message/provider reservation; deleted session rejects result; provider timeout template fallback.
