## Реализация

2. **SRC-001.02** — Найти для каждого банка product page, тарифный PDF и правила/условия, различить manual/news/tariff.

Ошибки и границы: 403/CAPTCHA/неясные права → blocked source и причина; сторонний mirror исключить; не заменять тариф справочником API.
