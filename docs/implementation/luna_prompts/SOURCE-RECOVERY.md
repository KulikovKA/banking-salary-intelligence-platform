## Что реализовать

Работай в offline режиме с Fake transport, локальными синтетическими fixtures и без банковского egress. Исследовательские CLI не подключай к worker как обход Gateway. Разрешённый live acceptance выполняется только когда существует активный source-specific G0-LIVE для точного URL, метода и цели.

1. Реализуй `backend/app/ingestion/tls.py`: scoped SSLContext, явный выбор system/certifi, дополнительный BANK_FETCH_EXTRA_CA_FILE. Корректная проверка PEM/CA, hostname/chain, никаких verify=False, global injection и модификаций certifi package files. TLS config failure — typed error. CA не добавляется в Windows Root автоматически. Добавь settings с безопасными значениями по умолчанию, пример переменных и тесты. Используй фактический httpx2 либо обоснованно согласуй клиент; не делай скрытую замену dependencies.
2. Реализуй robots parsing через Protego или эквивалент с доказанной поддержкой групп, wildcard, `$`, более специфичных allow/disallow. Сохраняй raw robots/hash/time/UA/matched group; HTML challenge и неизвестное состояние блокируют dispatch. Tests должны воспроизводить границу `*`/Yandex и реальный сценарий `*.pdf$`, а также 403/HTML200.
3. Реализуй FetchGateway как единственную точку egress. Перед dispatch и каждым redirect проверяй active policy с exact scheme/host/path/методом/redirect allowlist/сроком/отзывом/rate/storage-reuse основаниями. Unknown policy и offline дают typed blocked без сети. Проверяй DNS и реальный peer IP, защищай от DNS rebinding/SSRF, HTTPS только, 50MiB max, timeouts, ≤5 redirects, concurrency=1/host. Проверяй MIME/magic и HTML error markers.
4. Реализуй immutable LocalBlobStore: temp+streaming SHA256+size limit+fsync+atomic rename на том же volume. Только после завершения файла создавать DB ref. Blob dedup по hash; observation создаётся на каждую попытку; version только для нового content. 304 без cached verified blob — error. Quarantine до content acceptance.
5. Раздели error codes: TLS_UNTRUSTED_ROOT/TLS_CHAIN_INVALID/TLS_HANDSHAKE_EOF/CONNECT_TIMEOUT, ROBOTS_DISALLOWED/ROBOTS_UNKNOWN/POLICY_BLOCKED, HTTP_FORBIDDEN/CHALLENGE, FORMAT_INVALID/SIZE_LIMIT. Retry только transient errors/5xx с bounded exponential backoff+jitter; 429 учитывать Retry-After. Не повторять certificate/policy/robots/403/challenge автоматически. Предыдущая рабочая версия доступна, stale явно виден.
6. Реализуй discovery adapters kk/vtb на **synthetic HTML fixtures**: точные href/text/current-archive/effective-date candidates. Новые ссылки pending, а не auto-approved. Для ВТБ явный kind=xlsx и план безопасного XLSX parsing: текущая Source.kind этого не допускает. Не исполнять macros/external links и не получать external resources при parsing. Не заменяй все тарифы общими HTML обещаниями.
7. Реализуй approved manual import через существующий archive/content acceptance: bytes, original requested/final URL, operator, acquired_at, метод получения, policy/rights evidence, hash/MIME, dates/type/scope. Не создавать fake successful network observation или scheduled-fetch день. Не импортировать исследовательские реальные файлы в production без approval.
8. Parsed facts должны хранить blob/extraction hash, page/table-cell/quote, value/unit/basis/conditions, effective_from/to, observed_at, bank/segment/package/region и дату договора. Не заполнять unknown нулём/федеральным scope. Extraction key=(blob_hash,parser_version), facts/history append-only, publication требует reviewer.
