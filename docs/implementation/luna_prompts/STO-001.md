## Реализация

Контракт: BlobStore.put(stream)->BlobReceipt{id,sha256,size,type}; open(blob_id)->stream.

1. **STO-001.01** — Потоково писать temp в том же volume, ограничить размер и hash bytes.
2. **STO-001.02** — Выполнить fsync/atomic rename, затем зарегистрировать blob в БД; reuse digest.
3. **STO-001.03** — Разрешать чтение только через DB key, не path от пользователя.
4. **STO-001.04** — Сделать read-only reconciliation report missing/orphan; cleanup только orphan старше7дней без ссылок.

Ошибки и границы: Disk full/kill/invalid MIME не создаёт published metadata; path traversal и symlink escape reject; racing same hash безопасен.

## Тестирование

Roundtrip binary hash; concurrent identical put; injected write/rename/commit failure; traversal; reconciliation missing referenced blob.
