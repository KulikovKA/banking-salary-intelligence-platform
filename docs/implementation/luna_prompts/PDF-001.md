## Реализация

Контракт: DocumentParser.parse -> ParseResult physical_page1..N, printed_label?, quality_flags.

1. **PDF-001.01** — Проверить license decision PyMuPDF; при отсутствии использовать proposed pdfplumber и записать решение.
2. **PDF-001.02** — Запускать parser в isolated subprocess с quota120s/1GiB/1000pages.
3. **PDF-001.03** — Извлечь каждую физическую страницу и текст таблиц, не переставлять числа без связанного header.
4. **PDF-001.04** — Пометить image-only/garbled/missing-page и сложные сноски как needs_ocr/partial/review.

Ошибки и границы: Encrypted/corrupt PDF →typed error; no OCR hallucination; zero pages invalid; одна плохая страница не публикуется как complete.
