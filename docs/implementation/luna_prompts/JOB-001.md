## Реализация

Контракт: JobRun state machine DATA_FLOW; unique scheduled_slot, lease_token, heartbeat, retry_at.

1. **JOB-001.01** — enqueue_due транзакционно фиксирует slot и next_check_at.
2. **JOB-001.02** — Claim SKIP LOCKED, commit до сети, heartbeat30s/lease180s.
3. **JOB-001.03** — Выполнить dispatch по type и проверять fencing token при каждом commit результата.
4. **JOB-001.04** — Retry 3 attempts с backoff/jitter; expired lease requeue; deterministic failure blocked до изменения входа.

Ошибки и границы: Два scheduler/worker не выполняют одну публикацию; старый worker после lease expiry не пишет; process crash оставляет recoverable job.
