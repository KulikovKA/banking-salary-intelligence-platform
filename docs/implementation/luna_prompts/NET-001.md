## Реализация

Контракт: ApprovedUrl+ConditionalHeaders -> FetchResult{status,headers,redirects,blob?,error}.

1. **NET-001.01** — Проверять scheme/host/userinfo/port/DNS и реальный peer IP каждого redirect.
2. **NET-001.02** — Применить size50MiB/timeouts/redirect5/per-host concurrency1 и policy rate.
3. **NET-001.03** — Обработать ETag/Last-Modified, 304 только при cached blob; MIME/HTML markers.
4. **NET-001.04** — Сохранять каждую observation и error code; transient retry отдавать scheduler через retry_at.

Ошибки и границы: 429 учитывает Retry-After; 403/CAPTCHA blocked без bypass; HTML error200 не становится PDF; не читать internal IP.
