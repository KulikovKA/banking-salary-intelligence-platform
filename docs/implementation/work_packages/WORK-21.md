## REV-002 — Исправления по результатам независимого аудита

Reasoning: **Extra High**. [Полное ТЗ](../tasks/REV-002.md).

Контракт: Finding IDs и воспроизводимые проверки REV-001, центральные contracts не менять без ADR.

1. Разложить findings на локальные fixes, Critical/High первыми.
2. Добавить regression на исходное нарушение и минимальное исправление.
3. Запустить затронутые tests и необходимые интеграции, привязать commit к finding.
4. Обновить report resolved/remaining; если findings нет, explicit no-op report.

Ошибки: Архитектурное изменение требует ADR и решение пользователя; нельзя убрать проверку для зелёного отчёта.

Проверки: Для каждого finding original reproducer теперь pass; no regression соседних contracts.

Критерий: Все Critical/High исправлены с доказательствами либо явно BLOCKED; remaining limitations перечислены.

## Завершение блока

DONE только когда все внутренние этапы прошли свои AC, тесты и gates; отчёт `docs/reports/WORK-21.md` содержит список файлов, результаты проверок, ограничения и checkpoints. Синхронизировать MASTER_PLAN/WORK_INDEX и дочерние статусы TASK_INDEX/ТЗ; старый DETAILED_BACKLOG — исторический справочник. Если часть результата не готова, блок IN_PROGRESS или BLOCKED с причиной, не DONE.

Оформление уже проверенных результатов можно поручить Luna Light отдельным проходом. На Light нельзя заново решать, что тест или критерий выполнен.
