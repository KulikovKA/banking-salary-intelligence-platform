# Отчёт INF-002 — validated config и локальное окружение

**Статус:** IN_PROGRESS. **Дата:** 2026-10-09. **Область:** offline only. **G0:** formal gate ожидает ADR-006; владелец отдельно поручил этот офлайн-этап. Банковские сети и документы не затрагивались.

## Реализовано

- Добавлен `Settings` с типами, пределами, секретными значениями и production validation. Ошибки не включают environment values. Production требует БД, абсолютный storage path, HTTPS public origin, секрет с минимум 32 символами, auth и secure cookies; fake identity запрещён. Provider mode требует model, key, HTTPS endpoint и host allowlist; конкретный provider не выбран.
- Startup вызывает config validation до обработки запросов.
- Добавлены локальный Compose profile с PostgreSQL 18, backend и named storage; оба опубликованных порта привязаны к `127.0.0.1`.
- Добавлен backend Dockerfile и безопасный `.env.example` с локальными non-production настройками.
- Alembic и psycopg добавлены в project dependencies и `uv.lock`.
