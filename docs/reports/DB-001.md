## Реализовано

- SQLAlchemy metadata и единственная Alembic revision `0001_catalog` создают `banks`, `sources`, `source_policies`, `blobs`, `source_versions`, `source_fetches`, `job_runs` по начальной части `DATABASE_DESIGN.md`.

- Migration seeds только четыре bank codes. Повторное application seeding использует PostgreSQL `ON CONFLICT (code) DO NOTHING`; источники/тарифы не создаются автоматически.
- Добавлены idempotent job enqueue helper с конфликтом при повторном ключе для другого payload и явный transaction helper с commit на успешном выходе и rollback на исключении.
- Добавлены schema/config contract tests; transaction helper проверен с временной SQLite таблицей, но эта проверка не заменяет PostgreSQL schema integration.
